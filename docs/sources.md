## 재검증 방식

1. 원문의 시행일·귀속연도·표·부칙을 확인한다. 연도가 확인되지 않은 문서에 임의 연도를 부여하지 않는다.
2. `public/data/corpus.mjs`의 요약·출처·기간·years·확인일을 함께 수정한다. 일반 안내의 years는 앱에서 검색을 허용하는 맥락이며 해당 문서에 연도가 명시되었다는 뜻이 아니다. 화면의 period에서 이를 구분한다.
3. 세율 변경 시 `tax.mjs`의 연도별 규칙을 분리하고 경계 전후·공식 예시를 재시험한다.
4. 코퍼스 확대 시 실제 질문 평가를 추가하고 무관/범위 밖/연도 불일치 질문이 답변으로 통과하지 않는지 확인한다.
5. 2025년 당시 제27조·시행령·부칙을 추가 검증한 뒤에만 해당 연도 법령 검색에 포함한다.

질의회신·예규·판례는 현재 미수록이다. 이후 문서번호·세목·사실관계·적용 조문·공개 원문과 사용 조건을 검증한 자료부터 추가한다. 단순 키워드 검색은 복잡한 개인 사안을 해결하지 못하므로 근거 부족 시 답변을 유보한다.
