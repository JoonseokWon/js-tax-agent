# JS Tax Agent 인계

- UI·UX 적용 여부: 적용 / 화면 있음.
- 목적: 종합소득세·법인세·부가가치세의 공식 근거와 적용 시점을 검토하고 가정별 세액을 비교한다.
- 현재 버전: v0.3.0. GitHub 공개 프리릴리스 및 기존 개인용 사이트에 게시했다.
- 완료: 법인세·부가가치세 기본 계산, 공식 근거 21개, 세목별 회신·판례, 적용 기준일과 법령 연혁, 세액 비교와 메모, 법제처 목록 수집 도구.
- 결정: 법인세는 세무조정 후 과세표준을 사용한다. 부가세는 공제 여부를 확인한 매입세액을 직접 입력한다. 법령 개정과 원문 후보는 수집 후 사람 검토를 거쳐 계산과 검색에 반영한다.
- 검증: 데스크톱·모바일 기본 흐름과 세액 결과, 공식 근거 검색, 생성 AI 모의 응답을 확인했다. 법제처 실데이터 수집과 추가 세목의 실제 생성 답변은 별도 검증이 필요하다.
- 설계: 키는 서버 환경에만 두고 웹 입력·공개 소스·배포 번들에 포함하지 않는다. 호스팅의 개인 접근 권한을 유지한다.
- 실행: 프로젝트 폴더에서 `node server.mjs`. 승인된 로컬 설정을 읽을 때는 `node --env-file-if-exists=.env server.mjs`.
- 관련 문서: spec.md, plan.md, todo.md, design.md, sources.md, validation.md, law-discovery.md, api-key-setup.md.
- 계정별 설정·운영 진단의 상세 인계는 Git에서 제외된 `outputs/hosting-handoff-private.md`와 `outputs/hosting-validation-private.md`에 로컬 전용으로 보관한다.
- 다음: 법제처 이용 승인 후 기준일을 바꿔 첫 수집을 검증하고, 변경 후보의 조문·부칙을 비교한다. 생성 AI 실검증은 무료 크레딧 조건이 충족될 때 진행한다.
- 법제처 승인 후 프로젝트 폴더의 `collect-law.ps1`로 인증값을 숨김 입력하고 첫 기준 기록을 만든다. 승인 전 공개 예제 연결 확인 및 운영 재개 절차는 Git에서 제외된 로컬 기록에 둔다.
- Windows 기본 DNS가 실패하는 환경에서는 수집기에서 법제처 호스트를 DNS-over-HTTPS로 확인한다. 공개 예제 요청으로 TLS 연결과 법제처의 JSON 응답을 확인했다. 승인된 OC를 사용한 실제 수집 결과는 별도로 확인한다.
