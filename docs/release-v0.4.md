# JS Tax Agent v0.4.0

- 2026년 상속세·증여세의 산출세액을 A/B로 비교할 수 있습니다. 두 세목의 공식 근거 12개를 추가해 총 33개를 검색할 수 있습니다. 국세청 질의회신과 대법원 판례는 세목별로 원문을 확인한 사례를 담았습니다.
- 상속개시일이나 증여일을 입력하면 2026-01-01~2026-11-04에 적용된 법률·시행령·시행규칙과 관련 부칙의 공식 원문을 찾을 수 있습니다.
- 수집한 개정 조문이 답변 근거나 계산 규칙과 연결되면 **재검토 필요**로 표시합니다. 부칙 변경과 본문 비교 미완료는 별도로 안내합니다. 2026-11-04 법제처 조회에서는 추가 검토가 필요한 새 시행본이 없었습니다. Windows 로컬 실행은 승인된 인증값을 등록하면 자동 확인할 수 있습니다. 호스팅 사이트에서는 릴리스에 포함된 확인 결과와 확인일을 볼 수 있습니다.
- 비교 전에 사전증여 내역, 공제 사용 이력, 상속재산 분할일을 확인합니다. 한 안에서 같은 공제를 중복 적용하거나 상속 일괄공제와 기초·인적공제를 함께 넣으면 비교 전에 안내합니다. 증여공제를 이미 사용한 경우 직접 확인한 남은 한도와 이번 입력을 대조합니다.

Node.js 22.9 이상에서 압축을 풀고 프로젝트 폴더에서 `node server.mjs`를 실행한 뒤 `http://127.0.0.1:4317`을 여세요. 근거 검색과 비교는 키 없이 사용할 수 있습니다.

상속세·증여세 계산은 재산 평가·합산을 반영한 과세가액과 확인한 공제를 입력해 산출세액을 비교합니다. 실제 신고에서는 공제 자격과 한도, 특례, 할증과 세액공제를 별도로 확인하세요. 이번 릴리스의 새 세목 생성 AI는 모의 응답으로 검증했습니다.
