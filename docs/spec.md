# JS Tax Agent 요구사항

- UI·UX 적용 여부: 적용 / 화면 있음
- 목적: 종합소득세의 공식 근거를 찾아 이해하고, 가정 변화가 산출세액에 미치는 영향을 비교한다.
- 사용자: 개인사업자·프리랜서·세법 이슈를 검토하는 일반인과 실무자.
- 확정한 범위: 사용자 선택에 따라 종합소득세부터 구현. 국세청이 귀속연도를 명시한 2025년 기준, 장부에 의한 단일 사업소득의 일반 누진세율만 계산한다.

## 첫 버전

1. 검증된 국세청 안내·소득세법 요약 코퍼스의 한국어 검색, 관련 문단 검색과 근거 기반 답변. 원문 링크·종류·적용 시점·확인일을 함께 표시.
2. 기본 모드는 검색된 요약을 조합하는 로컬 답변. 선택적으로 로컬 Node 서버의 OpenAI Responses API를 통한 RAG 생성 답변을 제공한다. 키가 없을 때 생성 AI를 사용한 것으로 표시하지 않는다.
3. 기준안/비교안의 수입·필요경비·소득공제를 입력하여 과세표준·산출세액·한계세율·차이를 표시. 세율 구간과 계산 과정을 공개한다.
4. 질문에서 비교 화면으로 연결, 근거 보관함 검색, 검토 메모 Markdown 다운로드, 질문/계산 초기화.
5. 질문과 계산값은 기본적으로 브라우저 메모리에만 유지. 생성 AI는 사용자가 해당 버튼을 눌러야 질문과 검색 문단을 외부 API로 전송한다. 금액 입력은 전송하지 않는다.

## 제외 / 후속

- 전 세목, 모든 국세청 질의회신·판례의 전수 수집, 실시간 법령 동기화, 공식 질의회신 데이터 연계.
- 2026년 이후 계산, 근로소득·금융소득 합산, 추계신고, 분리과세, 결손금·특례·세액공제·감면·가산세·기납부세액·지방소득세·확정 납부/환급 계산.
- 로그인, 상담 의뢰, 개인정보 수집, 파일 업로드, 자동 신고.

## 입력·출력과 흐름

- 질문 예: “필요경비는 어떤 기준으로 인정되나요?” → 관련 공식 근거 요약과 원문 링크, 개별 비용 인정에 필요한 사실 확인 안내.
- 비교 예: 수입 8천만원, 경비 2천만원, 공제 150만원 → 과세표준 5,850만원, 국세 산출세액 828만원. 경비를 3천만원으로 변경 → 601만5천원, 차이 226만5천원.
- 흐름: 질문 입력 → 근거 확인 → 세액 비교 이동 → 가정 입력 → 비교 확인 → 메모 다운로드.
- 근거 보관함에서 주제/키워드 검색 → 원문 확인 또는 해당 내용 질문.

## 예외와 완료 기준

- 검색 근거가 약하거나 범위 밖 질문은 답변을 단정하지 않고 수록 범위와 재질문 예시 제공. 해석의 합법성을 판정하지 않는다.
- 공백·2천자 초과·민감 식별정보 형식은 질문을 유지하고 입력 수정을 안내.
- 금액은 0~1조원 정수, 빈 값/음수/문자/소수 거부. 비용이 수입을 초과하면 결손금 미지원 안내. 오류 시 이전 결과를 유효한 결과처럼 남기지 않는다.
- API 미설정·실패·시간 초과는 로컬 답변으로 조용히 위장하지 않고 오류와 재시도 경로 제공.
- 핵심 세율의 모든 경계와 상위 구간, 검색·답변 유보·입력검증·API 계약·정적 빌드 검증.
- 데스크톱/모바일 실제 화면과 질문→근거→비교→다운로드 흐름 확인.
- 문서/실행 스크립트/소스/테스트를 공개 GitHub 저장소와 프리릴리스로 배포. 비밀키와 사용자 자료 제외.

## 제약과 가정

- 공식 자료는 2026-10-29 확인한 제한된 스냅샷이다. 원문 개정 시 재검증 필요.
- 소득세법 최신 조문은 현재 시행 시점을 명시하여 일반 원칙 참고로 제공하고, 2025 계산세율은 별도 국세청 연도별 표를 사용한다.
- 개별 국세청 질의회신은 검증된 자료 확보 전 수록 완료라고 표시하지 않는다.
- 외부 API 실호출은 키 확보 전 미검증. 호스팅 정적 체험판에서는 로컬 근거 답변과 계산만 제공. GitHub 소스 공개와 별개로 Sites는 기본 개인 접근 권한을 유지.
