## 조사·수정 이력

- 첫 화면 이동 시 제목으로 자동 스크롤해 헤더가 가려지는 동작을 확인 → 메뉴 전환은 페이지 상단, 결과 생성은 결과 카드 상단으로 이동하도록 수정·재확인.
- 보조 글씨가 작아 실제 모바일 읽기가 불편함 → 핵심 도움말/본문 크기 확대, 개인정보 안내의 불필요한 줄바꿈 수정.
- 연속 빌드 시 이전 build-manifest 자체를 다시 해시하는 문제 → 프로젝트 내부 dist 절대 위치를 검사한 뒤 새로 빌드. 재현성 검사 추가·통과.
- 브라우저 AX에서 details의 역할이 버튼으로 보이지만 DOM 역할 검색으로 매칭되지 않음 → 실제 summary 요소로 검증. 앱 기능 오류는 아니었음.
- GitHub 연결 도구에는 저장소 생성/Release 기능이 없어 공식 REST 어댑터 사용. 샌드박스 계정에는 인증이 없었지만 일반 Windows 계정의 기존 GCM 인증으로 사용자 일치 확인 후 공개 저장소 생성 성공.
- Sites 배포 도구의 네트워크 제한·Git 소유자 차이·아카이브 위치 제약을 각각 확인하여 해당 프로젝트 범위의 실행 설정과 outputs/ 경로로 해결. 배포 도구 반환 상태 succeeded 확인.
