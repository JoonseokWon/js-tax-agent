# JS Tax Agent v0.3.0

- 2025년 종합소득세에 2026년 법인세와 일반과세자 부가가치세를 추가했습니다.
- 2026년에 시작하는 1년 사업연도의 국내 일반 영리법인 산출세액과, 일반과세자의 국내 10% 과세 거래에서 납부·환급 방향을 각각 비교할 수 있습니다.
- 공식 근거 21개를 세목·종류·문서번호로 검색할 수 있습니다. 새 법인세·부가세 회신과 판례에는 당시 사실관계와 적용 한계가 표시됩니다.
- 절세 검토 순서에서 기준일, 법령 연혁·부칙, 증빙을 확인할 수 있습니다. 계산 범위를 벗어난 기준일은 계산을 보류합니다.
- 법제처 목록 수집 도구는 적용 기준일, 현재 시행본, 시행예정본을 나눠 검토 후보를 저장합니다. 별도 이용 승인이 필요하며, 수집 자료는 검토 후 반영합니다.

Node.js 22.9 이상에서 압축을 풀고 프로젝트 폴더에서 `node server.mjs`를 실행하세요. 근거 검색과 세액 비교는 키 없이 사용할 수 있습니다. 생성 AI 연동은 모의 응답으로 검증했습니다. 추가 세목의 실제 생성 답변과 법제처 인증을 사용한 일괄 수집은 검증 대기 상태입니다.
