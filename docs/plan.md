# 구현 계획

## v0.2

1. 공식 질의회신·판례의 문서번호, 사실관계, 판단과 적용 한계를 확인한다.
2. 한국어 주제·문서번호 검색과 자료 종류 필터를 연결한다.
3. 제공 근거만 인용하는 서버 AI, 오류 안내와 안전한 비밀값 설정을 구현한다.
4. 기존 개인 전용 Site의 Worker 빌드와 게시 절차를 적용한다.
5. 자료 검색·세액 비교·메모·반응형·접근성 및 생성 답변을 구분해 검증한다.
6. 공개 문서에는 앱 사용법과 기능 검증 범위를 기록하고, 계정별 운영 진단은 로컬 비공개 기록에 보관한다.

## 다음 작업

- 호스팅 생성 AI의 정상 답변 평가를 완료하기 전에는 검증 완료로 표시하지 않는다.
- 종합소득세 작업 후 법인세, 부가가치세 순서로 공식 계산 규칙·입력·예외·사례를 검증하고 확장한다.
- 외부 API 사용은 승인된 범위 안에서만 진행하며 별도 결제나 자동 충전을 설정하지 않는다.
