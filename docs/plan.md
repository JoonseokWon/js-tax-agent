# 구현 계획

## 상속세와 증여세

1. 국가법령정보센터와 국세청에서 일반세율, 과세최저한과 공제 범위를 대조한다.
2. 과세가액과 확인한 공제를 받는 공통 계산을 연결하고 두 세목의 경계값을 검사한다.
3. 질문·비교·보관함에 세목을 추가한다. 적용 기준일과 연혁 링크, 데스크톱·모바일 계산 및 검색 흐름을 확인한다.
4. 법제처 수집기에 두 세목을 추가한다. 승인된 OC로 실수집한 뒤 검토한 회신·판례 원문을 자료에 반영한다.

## v0.3

1. 국세청과 국가법령정보센터 원문에서 법인세 일반세율·시행 시점, 부가세 기본세율·매입세액 공제 범위를 확인하고 자료 목록에 기록한다.
2. 기존 원 단위 검증을 재사용해 법인세·부가세 계산을 붙인다. 누진 경계, 환급, 오류 입력을 단위 테스트한다.
3. 세목별 자료를 검색·생성 요청·보관함에 연결한다. 다른 세목과 연도, 미수록 사례가 섞이지 않는지 확인한다.
4. 질문·비교 화면에 세목 선택, 예시, 적용 범위, 표, 메모를 연결한다. 데스크톱·모바일에서 키보드와 주요 흐름을 점검한다.
5. 절세 검토 단계와 시점 검증을 넣고, 세목별 추가 회신·판결의 사실관계와 당시 적용 규정을 확인한다. 법제처 목록에서 검토 후보를 수집하는 도구의 페이지 처리, 중복 제거, 기준일·시행예정 분리를 검사한다.
6. 검증 후 문서·인계·공개 릴리스 기록을 갱신한다. 실제 API 연결 검증은 무료 크레딧 조건과 별도로 관리한다.

## v0.2

1. 공식 질의회신·판례의 문서번호, 사실관계, 판단과 적용 한계를 확인한다.
2. 한국어 주제·문서번호 검색과 자료 종류 필터를 연결한다.
3. 제공 근거만 인용하는 서버 AI, 오류 안내와 안전한 비밀값 설정을 구현한다.
4. 기존 개인 전용 Site의 Worker 빌드와 게시 절차를 적용한다.
5. 자료 검색·세액 비교·메모·반응형·접근성 및 생성 답변을 구분해 검증한다.
6. 공개 문서에는 앱 사용법과 기능 검증 범위를 기록하고, 계정별 운영 진단은 로컬 비공개 기록에 보관한다.

## 다음 작업

- 호스팅 생성 AI의 정상 답변 평가를 완료하기 전에는 검증 완료로 표시하지 않는다.
- 외부 API 사용은 승인된 범위 안에서만 진행하며 별도 결제나 자동 충전을 설정하지 않는다.
