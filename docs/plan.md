# 구현 계획

## v0.2 구현 순서

후속 요청(2026-10-29): 종합소득세 v0.2 실제 AI 검증·배포를 마친 뒤 법인세, 부가가치세 순서로 확장한다. 각 세목의 공식 연도별 계산 규칙·공식 근거·사례·입력/예외를 검증하고 기존 소득세 계산과 분리한다. 사용자는 추가 결제 없이 무료 크레딧이 있을 때만 AI 연결과 배포를 승인했다. 대시보드 확인 후 사용할 무료 크레딧을 확보하지 못했으며 공식 결제 페이지는 별도 로그인이 필요하다. 무료 크레딧/추가 과금 방지 조건과 보안 키 선택이 확정되기 전 실제 API 호출·v0.2 게시는 보류한다.

1. 공식 자료 검증: 국세청 회신 3개와 대법원 판례 3개, 문서 메타데이터와 사실관계/한계 확보. 공식 원문을 실제로 열어 확인.
2. 코퍼스/검색: 역사적 참고 사례 필드, 주제/문서번호 검색, 상호 보완 회신 동시 검색, 자료 종류 필터. 기존 계산 범위 유지.
3. AI/비밀값: 문장별 인용 구조, 오류 구분, 안전한 로컬 키 입력과 실연결 확인 명령. 서버/호스팅 공유 핸들러와 비용 발생 API 동시 실행 제한.
4. 호스팅: 기존 Sites를 Worker ESM으로 전환. 자산·서버 코드 단일 번들, 비밀값은 런타임 주입. 기존 Site ID와 개인 접근 권한 유지.
5. 화면/검증: 출처 유형·문서번호·사실관계·한계와 AI 설정 상태를 화면/다운로드에 연결. 실제 브라우저, 회귀 테스트·번들/API 테스트, 실키 확보 시 실호출.
6. 배포/기록: v0.2.0 프리릴리스·소스/실행 ZIP·CI, spec/design/todo/sources/validation/handoff를 실제 결과로 갱신.

1. **범위와 설계**: spec/design 작성, 공식 자료 확인. 선행: 폴더·지침 확인, 사용자 세목 선택. 확인: 연도/출처/계산 범위 명시.
2. **근거와 계산 엔진**: public/lib·data, 한국어 검색/답변 유보와 정수 기반 누진세액. 선행: 자료 확인. 확인: 세율 경계·계산 예시·검색 평가 테스트.
3. **화면**: public/index.html·style.css·app.js. 선행: 엔진. 질문/근거/비교와 보관함, 상태·접근성·메모 다운로드 구현. 확인: 실제 브라우저 흐름과 두 화면 크기.
