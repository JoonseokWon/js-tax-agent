# 화면 설계

## v0.2 추가

- 질문 카드에서 자료 요약과 생성 AI를 구분하고 AI 설정 상태·연결 확인 버튼·보안 설정 안내를 제공한다. 키 입력란을 웹 화면에 두지 않는다.
- 답변에는 인용 문장·출처 번호·추가로 필요한 사실·적용 한계를 분리한다. 원문 출처의 문서/사건번호·회신/선고일·사실관계·해석 한계를 펼쳐 볼 수 있다.
- 보관함은 전체/국세청 질의회신/판례/안내·법령 필터와 키워드/문서번호 검색을 함께 제공한다. 자료 개수는 데이터에서 계산한다.
- 과거 사례는 ‘참고 사례 · 현재 적용 여부 별도 확인’ 배지를 표시한다. 회신연도/선고연도를 2025년 계산 귀속연도처럼 표시하지 않는다.
- AI 미설정 시 설정 방법을 안내하고 질문 입력을 유지한다. 연결 확인은 명시적 버튼으로만 API를 호출하며, 단순 페이지 방문은 API 비용을 발생시키지 않는다.

- UI·UX 적용 여부: 적용 / 화면 있음
- 주행동은 세금 질문 입력. 좌측 내비게이션(질문하기/세액 비교/근거 보관함), 중앙 질문과 결과, 우측 작은 안내 카드. 모바일은 상단 내비게이션과 한 열 읽기 순서.
- 첫 화면: “세금 고민, 근거부터 차근차근.” 제목, 연도 배지, 넓은 질문 입력 카드, 추천 질문, 작동 원리 3단계와 세액 비교 카드. 장식용 이미지보다 질문과 근거가 먼저 보이도록 한다.
- 결과: 사용자 질문, 답변 방식/연도, 번호별 근거 요약, 원문 펼침, 확인할 사실, 비교 이동/메모 다운로드. 근거가 없으면 답변 유보와 재질문 예시.
- 비교: 기준안/비교안 입력, 단위 원, 예시값 표시. 수입·경비·공제를 수정한 후 “세액 비교하기”. 결과는 차이 카드와 두 막대, 비교표, 세율표, 제외 항목. 비교 결과를 납부액이나 절세 확정액으로 부르지 않는다.
- 보관함: 종류·확인일·시행 시점을 포함한 공식 자료 목록, 키워드 필터, 원문 링크.
- 벤토는 도입부의 연결 기능을 설명하는 두 카드에만 사용. 비교는 표, 자료는 목록으로 제공.

## 공통 시각 규칙

- 배경 #f5f7fa, 표면 흰색, 본문 #202c3d, 보조 #58677d. 강조 #2670eb, 보조 포인트 따뜻한 주황 #b65a19. 차분한 파랑으로 주행동을 통일.
- 시스템 한국어 글꼴 Malgun Gothic 우선, 제목 34~40px/본문 15~16px/보조 13px. 행간 1.6, 8px 간격 체계, 카드 20px 모서리, 테두리와 약한 그림자.
- 버튼/입력 최소 44px 터치 영역. 라벨은 항상 표시, focus-visible 3px 외곽선, 주요 문구는 배경 대비 4.5:1 이상 목표.
- 토스 공개 라이팅 원칙의 명확성·간결성·예측 가능한 행동 안내 참고: https://toss.tech/article/8-writing-principles-of-toss . 브랜드 로고/화면 복제 없이 자체 디자인.

## 상태와 확인

- 빈 질문/숫자 오류는 입력 바로 옆 안내, 입력 유지와 aria-invalid, 결과 오류는 role=alert.
- 검색 중에는 버튼 비활성/진행 문구/aria-busy, 결과는 라이브 영역과 결과 제목으로 포커스 이동.
- 검색 결과 없음/범위 밖은 추가 정보를 요구하고 근거를 꾸미지 않음. 생성 AI 실패는 사용자가 로컬 방식으로 재시도 가능.
- 탭 선택은 aria-current와 hidden section, 내부 이동 시 제목에 포커스. 링크·버튼을 의미에 맞게 사용.
- 1440×1000, 390×844에서 가로 넘침·잘림·줄바꿈·키보드 순서·모든 버튼을 확인. DevTools 기기 모드 또는 지원되는 브라우저 크기 변경으로 확인.
