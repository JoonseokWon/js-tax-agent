# JS Tax Agent v0.1.0

종합소득세를 공식 근거와 함께 살펴보고 가정별 산출세액을 비교하는 첫 공개용 체험판입니다.

- 국세청 안내 기반 한국어 검색·근거 요약과 공식 자료 보관함.
- 2025년 단일 사업소득의 필요경비·소득공제 시나리오 비교.
- 질문·출처·계산 조건을 담은 검토 메모 다운로드.
- 밝은 한국어 화면, 모바일 대응, 입력 오류·빈 검색 상태·키보드 포커스.
- 선택형 로컬 OpenAI Responses RAG 어댑터. 기본 답변은 생성 AI를 사용하지 않습니다.

Node.js 22.9 이상에서 압축을 풀고 `node server.mjs`를 실행한 뒤 `http://127.0.0.1:4317`에 접속하세요. 별도 의존성 설치나 API 키 없이 기본 기능을 사용할 수 있습니다. 생성 AI 설정은 README를 확인하세요.

검증: 자동 테스트 17개 통과, 1440×1000/390×844 실제 화면·질문→근거→비교→다운로드·입력 오류 복구 확인. 실제 OpenAI API 호출은 키가 없어 미검증입니다.

범위: 국세청 안내 4개와 참고용 법령 1개. 개별 질의회신·판례는 미수록이고 2026년 이후 세액 계산은 지원하지 않습니다. 지방소득세·세액공제·감면·가산세·기납부세액 등은 제외하므로 결과는 확정 납부액이 아닙니다.
