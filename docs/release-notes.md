# JS Tax Agent v0.2.0

국세청 질의회신 3건과 대법원 판례 3건을 추가하고 실제 OpenAI 질의응답을 검증한 로컬 실행형 프리릴리스입니다.

- 총 11개 공식 자료, 문서/사건번호 검색과 자료 종류 필터.
- 등록 전 비용과 과세기간 이월을 구별하는 회신 동시 검색, 판례의 사실관계·판단·파기환송·적용 한계 표시.
- 서버 Responses API, 문장별 제공 근거 검증, 키 비노출, 인증·크레딧 소진·속도 제한·통신 오류 안내.
- AI 설정/실연결 상태, 공개 예시 연결 확인, 문장별 근거와 사례를 포함한 검토 메모 다운로드.
- 기존 2025년 단일 사업소득 세액 비교 유지, 모바일 답변 버튼 배치 개선.

Node.js 22.9 이상에서 압축을 풀고 `node server.mjs`를 실행한 뒤 `http://127.0.0.1:4317`에 접속하세요. 기본 검색과 비교는 API 키나 패키지 설치 없이 사용할 수 있습니다. 생성 AI는 안전하게 설정한 서버 키가 필요하며 `node --env-file-if-exists=.env server.mjs`로 실행합니다. 키·개인 자료·계정 결제 화면은 패키지에 포함하지 않습니다.

검증: 자동 테스트 31개, 정적/Worker 빌드 계약, 1440×1000/390×844 화면 확인. `gpt-5.4-mini`로 개업 전 비용·초과인출금 이자 질문 2건의 실제 응답·인용·적용 한계를 확인했고, 판례 답변의 메모 다운로드도 검증했습니다. 이 두 예시가 모든 질문의 정확성이나 전문가 검토를 대신하지 않습니다.

호스팅 체험판은 v0.1.0을 유지합니다. v0.2 Worker 소스·번들은 검증했지만 로컬 키를 Sites 서버 비밀값으로 안전하게 전달할 경로를 확보하지 못해 호스팅 AI 배포는 대기 중입니다. GitHub 공개와 개인 접근 호스팅의 상태를 구분합니다.

계산 범위는 2025년 단일 사업소득 국세 산출세액이며, 2026년 이후 세액 계산·법인세·부가세는 아직 지원하지 않습니다. 지방소득세·세액공제·감면·가산세·기납부세액 등을 제외하므로 최종 납부액이 아닙니다. 수록한 과거 회신·판례는 현재 사안의 적용을 확정하는 자료가 아닙니다.
